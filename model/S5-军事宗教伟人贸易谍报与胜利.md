## 1. 军事模型【DB 实测】

### 1.1 伤害期望公式【DB+规则】

```
伤害 ≈ 24 × 2^((攻方力 − 守方力) / 25)       （COMBAT_BASE_DAMAGE=24【DB】；÷25 为社区拟合口径）
```
- **每 +10 力 ≈ +30% 伤害**；+25 力 ≈ 伤害翻倍；差 30+ 力 = 碾压（两次行动内消灭）。
- 城防 = 城内最强近战单位力（+城墙加成）；攻城单位（石弩类）对城防有专精。

## 2. 宗教模型【DB+规则】

### 2.1 发教
- 万神殿：25 鸽（首神谕）；大预言家：圣地 + 神社 + 政策「启示」；成本随伟人序。
- 宗教单位：传教士/使徒（信仰购买；强度与传教次数见 Units.ReligiousStrength/SpreadCharges【DB 字段存在】，具体数值待核）；神权政体可买全部军事单位。

### 2.2 传播与压制参数【DB】
- 城市压力：圣城每人口 200 压力、无神论城 50、邻城距离 10、圣城 ×4（`RELIGION_SPREAD_*`）。
- 传教决策：使徒传教 2 次内改宗中小城市（【经验】阈值：人口≤5 的城 1 使徒 2 次传教可改；大城需审判官+使徒组合）。
- 宗教胜利：**每个文明的 >50% 城市改宗**；防守方使徒/审判官在圣地里战斗 +15 力（`COMBAT_RELIGIOUS_HOLY_CITY_TILE=15`）。

## 3. 伟人模型【DB】

### 3.1 点数与成本
- 点数来源：对应区域 +1/回合 + 每级建筑 +1（S3 §2.3 实测表）。
- **招募成本基数（GreatPersonBaseCost【DB】）：远古 30 → 古典 60 → 中世纪 120 → 文艺复兴 240 → 工业 420 → 现代 660 → 原子 960 → 信息 1320**，同类型每招募 1 人递增。
- 抢伟人：政策卡（灵感/发明 +2 点）+ 神谕（+2 点/城）+ 平加拉「资助」（+100% 点）。

### 3.2 值得抢的伟人【经验】
- 大科学家：希帕蒂娅（图书馆）、牛顿（大学+免费）、爱因斯坦（大学/实验室加成）、航天系大科（登月/火星项目加速）。
- 大工程师：伊姆霍特普（奇观）、达芬奇（工坊+）、**航天大工（项目 +100% 锤或直接完成部件）**——飞天关键，可用金币/信仰买空（见 README 引用攻略）。
- 大商人：马可波罗（商路+1）；大提督/大将军：军备窗口。
- 大作家/艺术家/音乐家：文化线全部要（作品=旅游）。

## 4. 商路与贸易【DB 实测】

### 4.1 容量来源【DB+规则】
- 对外贸易市政 +1；商业中心市场/港口灯塔每城 +1；商人共和国政体 +2；大商人个别 +1。神级标准容量：T100 约 6–10 条。

### 4.2 收益构成【DB（District_TradeRouteYields 实测）】
- 国际商路（到外国城市）：市中心/港口/商业中心 +3 金；学院 +1 科、剧院 +1 文、圣地 +1 鸽、军营/工业区 +1 锤（按终点区域）。
- 国内商路（到自己城市）：终点区域类型给 +1 粮/+1 锤。
- 额外：贸易联盟政策 +1 文 +1 科/条；每 2 金/起点区域【DB 参数】。

### 4.3 决策规则
- **新城内商路养人口**（+2 粮+2 锤/条）；稳定后转国际商路拿金/科/文。
- 连城邦：完成城邦任务+使者；宗主加成（见 S4 外交区）。
- 文化线：连盟友（文化联盟 + 商路旅游）。

## 5. 谍报【DB 参数】

- 容量：基础 1 + 外交区/情报局/政策（【经验】）。
- 任务成功率：等级（`ESPIONAGE_MAX_LEVEL=4`）+ 增益来源（`ESPIONAGE_BONUS_GAIN_SOURCES=2`）+ 逃跑基准 10%（`ESPIONAGE_ESCAPE_BASE_CHANCE=10`）。
- **高价值行动**：窃取科技（目标已研科技的随机尤里卡——对落后的你 = 40% 免费进度）；破坏宇航中心（毁掉对手飞天进度）；培养（钱）——期望收益排序：科技线「窃取科技」＞文化线「窃取巨作」＞破坏。
- 防守：反间谍任务（情报局）；政策卡/科技提升警力。

## 6. 胜利进度估算【DB+经验】

### 6.1 科技胜利
- 项目链（Projects 实测）：发射地球卫星 900 + 登月 1500 + 火星反应堆/住所/水培各 1800（共 5400）+ 系外行星探索 2100 = **11700 锤**，再加宇航中心 1800。
- 系外飞船到达：50 光年基准，每座地面激光站 −1（`PROJECT_TERRESTRIAL_LASER`/`ORBITAL_LASER` 各 600 锤）。
- 估算：T = 当前回合 + 11700/帝国总锤（约 300–500 锤/回合 → 20–33 回合）+ 飞行 40–50 回合。神级合格线 T230–260。

### 6.2 文化胜利
- 国内游客 = 累计文化/100；国际游客 = 累计旅游（对每文明）。需要旅游 > 对手国内游客。
- 旅游来源：伟人作品（每件 +2~4/回合）、奇观、国家公园、摇滚乐队/社交媒体。
- 估算规则：文化线 T200 前累计旅游 ~1000+ 且每回合增长 50+ → T220–280 胜利【经验】。

### 6.3 宗教胜利：§2 的改宗进度 = 已改宗文明数；每文明改宗预算 ≈ 2–4 使徒 + 1–2 审判官【经验】。

### 6.4 统治胜利：占领全部原始首都；关键 = §1.3 军备线 + 核武/机甲收尾。

### 6.5 外交胜利：20 外交点 = 议会决议 + 竞赛 + 城邦宗主 + 奇观（自由女神）；「外交资本」未来政策卡 +2 点/回合（信息时代市政「巧实力主义」）。
